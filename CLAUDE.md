# voice_gen

## Environment

Use the conda env `sound` for this project (`/opt/miniconda3/envs/sound`).
Run Python as `conda run -n sound python ...` or `/opt/miniconda3/envs/sound/bin/python ...`.

To rebuild the env on another machine, follow [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md).

`tempo.py` calls the system `ffmpeg` (Homebrew) for time-stretching.
